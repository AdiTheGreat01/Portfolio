MonkGully

A gaming-gear landing page built to sell the fantasy — bold visuals, layered motion, and a layout engineered to convert, using nothing but HTML, CSS, and JavaScript.

HTML CSS JavaScript Responsive Design
Live Demo GitHub
assets/monkgully/hero.jpg

Overview

MonkGully is a landing page concept for a gaming-gear brand, built to feel high-energy and premium without leaning on any framework. The focus was on layout rhythm, contrast, and motion — using pure HTML, CSS, and JavaScript to create a page that scrolls like a product trailer, section by section.

Key Features

Scroll-Triggered Reveals

Sections animate into view using an IntersectionObserver, keeping the page light without a library.

Smooth Anchor Navigation

In-page links scroll smoothly to their targets for a seamless one-page browsing experience.

Responsive Hero Layout

A split hero section that gracefully collapses into a stacked layout on smaller screens.

Dark Mode Support

A persisted theme toggle switches the whole page between light and dark palettes instantly.

Technical Highlights

One of the more interesting problems was reworking the hero section's visual hierarchy — moving from a flat, static banner to a layered composition with clearer depth and focus.

Tech Stack

HTML5 CSS3 (Flexbox & Grid) JavaScript (ES6+) IntersectionObserver API

What I'd Do Next

  • Add a lightweight build step for image optimization and CSS/JS minification.
  • Introduce a small component pattern to reduce repeated markup across sections.
  • Add automated accessibility and performance checks (Lighthouse CI).
  • Expand the product showcase into a filterable grid with real product data.

MonkMind

A quiz platform where users build custom quizzes, browse the community's, and take timed challenges — built with vanilla HTML, CSS, and JavaScript, no frameworks.

HTML5 CSS3 JavaScript (ES6+) localStorage Canvas API
Live Demo GitHub
assets/monkmind/hero.jpg

Overview

MonkMind is a full quiz application — registration, quiz creation, browsing, timed play, and scored results — built entirely in vanilla JavaScript to focus on front-end architecture rather than framework tooling. Accounts and quiz data are stored client-side via localStorage, since the goal was to build and polish the full UI/UX flow, not stand up a backend.

Key Features

Quiz Builder

A dynamic accordion interface for adding, editing, and reordering questions.

Search & Filter

Browse community quizzes by keyword, category, or difficulty.

Timed Play Mode

Thirty seconds per question with automatic advance once time runs out.

Scored Results

An accuracy ring visualizes performance, paired with a full answer review.

Tech Stack

HTML5 CSS3 (Grid & Flexbox) JavaScript (ES6+) localStorage Canvas API

Screenshots

assets/monkmind/screen-builder.jpg
assets/monkmind/screen-browse.jpg
assets/monkmind/screen-play.jpg
assets/monkmind/screen-results.jpg

Engineering Highlights

  • Every interactive piece is hand-built and keyboard-accessible: a modal with a focus trap and Escape-to-close, an accordion operable via Enter/Space, and quiz answers implemented as a proper radiogroup with arrow-key navigation — no UI library involved.
  • Zero dependencies. No frameworks or build step — routing, state, and rendering are all plain JavaScript.
  • Respects prefers-reduced-motion and maintains visible focus states throughout the interface.

What I'd Improve

  • Move from localStorage to a real backend and database.
  • Add proper hashed-password authentication with sessions.
  • Add unit tests for the scoring and filtering logic.
  • Let users edit or delete their quizzes and view their attempt history.

Doodle Calculator

A hand-drawn, sketchbook-style calculator built with vanilla HTML, CSS, and JavaScript — chained calculations, keyboard support, and careful number formatting, no frameworks or dependencies.

HTML5 CSS3 JavaScript (ES6+) CSS Custom Properties ARIA / A11Y
Live Demo GitHub
assets/doodle-calculator/hero.jpg

Overview

Doodle Calculator is a vanilla-JS calculator built to focus on clean state management and interaction logic rather than lean on a framework. Chained calculations, keyboard input, and click input all route through the same handler functions, and the display formatting handles edge cases — floating-point rounding, division by zero, very large or very small results — that a lot of tutorial calculators skip.

Key Features

Chained Calculations

Enter multi-step expressions like 5 + 3 × 2 and watch them evaluate left to right as you type.

Live Expression Preview

The full expression builds above the result in real time, so you always see what's being calculated.

Full Keyboard Support

Every button — digits, operators, equals, clear, delete — mirrors a keyboard shortcut through shared handler logic.

Smart Number Formatting

Very large, very small, or imprecise decimal results are rounded and switched to exponential notation automatically.

Tech Stack

HTML5 CSS3 (Grid, Flexbox, Custom Properties) JavaScript (ES6+) Google Fonts

How It Works

The project is split by concern: markup, styling, and logic each live in their own file, with button behavior driven by data-action attributes rather than hardcoded per-key handlers.

index.html style.css script.js

Challenges & Learnings

  • Keeping click and keyboard input in sync

    Both input methods needed identical visual feedback and logic, which meant funneling both through the same handler functions instead of duplicating logic across two event listeners.

  • Formatting numbers without breaking the layout

    Floating-point results needed rounding before display, and very large or small numbers needed a fallback to exponential notation so the display never overflows.

Future Improvements

  • Proper operator precedence instead of left-to-right evaluation.
  • A basic calculation history panel.
  • Unit tests for the calculate() and formatNumber() functions.
